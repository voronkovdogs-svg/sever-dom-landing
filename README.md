# Север Дом

Коммерческий одностраничный лендинг вымышленной строительной компании: каталог проектов, пошаговый калькулятор, сравнение комплектаций, кейсы, формы и серверная обработка заявок.

> Это портфолио-концепт. Компания, контакты, проекты, цены, кейсы, цифры и отзывы вымышлены. Перед коммерческим запуском их нужно заменить.

![Превью проекта](docs/screenshot.png)

## Стек

- Next.js 16, React 19, TypeScript strict;
- Tailwind CSS 4 и локальные дизайн-токены;
- React Hook Form + Zod;
- Radix/Shadcn primitives для dialog, sheet, tabs, accordion, radio, checkbox, slider и progress;
- Vitest + Testing Library;
- Playwright + axe-core.

Требуется Node.js 22.13+ и pnpm 11+.

## Запуск на вашем ПК

    pnpm install
    copy .env.example .env.local
    pnpm dev

Откройте http://localhost:3000.

Production-режим:

    pnpm build
    pnpm start

Сайт работает на ПК как полноценное Next.js-приложение. Чтобы открыть его в локальной сети, настройте разрешенный адрес и правила брандмауэра самостоятельно; не публикуйте Telegram-секреты.

## GitHub

Проект подготовлен для GitHub: есть .gitignore, lockfile и CI в .github/workflows/ci.yml.

    git init
    git add .
    git commit -m "Build Sever Dom landing"
    git branch -M main
    git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
    git push -u origin main

GitHub Pages обслуживает только статические файлы и не выполняет Route Handler /api/leads. Поэтому Pages не выбран как основной хостинг: он отключил бы серверную валидацию и Telegram-доставку. GitHub здесь используется для хранения кода и автоматических проверок, а полностью рабочий вариант запускается на ПК или на Node.js-хостинге.

## Переменные окружения

| Переменная | Назначение | Секрет |
| --- | --- | --- |
| NEXT_PUBLIC_SITE_URL | Канонический адрес, sitemap и OG | нет |
| LEAD_DELIVERY_MODE | mock или telegram | нет |
| TELEGRAM_BOT_TOKEN | Токен Telegram-бота | да |
| TELEGRAM_CHAT_ID | ID чата для заявок | да |
| ALLOWED_ORIGINS | Допустимые Origin через запятую | нет |

.env.local не коммитится. В mock-режиме API валидирует заявку и возвращает диагностический ID, но не сохраняет данные.

## Telegram-доставка

1. Создайте Telegram-бота и добавьте его в закрытый чат.
2. Запишите токен и ID чата только в .env.local.
3. Установите LEAD_DELIVERY_MODE=telegram.
4. Перезапустите сервер.

Интеграция выполняется только в lib/lead-delivery.ts. Секреты не попадают в клиентский bundle. Встроенный rate limit работает в памяти процесса и подходит только как best-effort защита; для масштабируемого production нужен внешний storage.

## Команды проверки

    pnpm lint
    pnpm typecheck
    pnpm test
    pnpm test:e2e
    pnpm build

Playwright впервые требует браузер:

    pnpm exec playwright install chromium

Финальный локальный прогон: lint, TypeScript и production build проходят; Vitest — 13/13; Playwright — 7 успешных сценариев и 1 ожидаемый пропуск desktop-only; axe не нашел серьезных или критических нарушений на главной странице и в диалоге проекта. HTTP-проверка подтверждает 200 для основных маршрутов, 404 для неизвестного адреса, 200 для валидной и 400 для невалидной заявки.

Lighthouse в текущей среде не был завершен: npm-соединение неоднократно обрывалось при загрузке самого Lighthouse. Это ограничение инструмента проверки, а не runtime-зависимость сайта; пакет не добавлен в проект.

## Где менять контент

- content/site-data.ts — проекты, кейсы, отзывы, FAQ, факты и этапы;
- config/calculator.ts — демонстрационные ставки и коэффициенты;
- app/page.tsx — структура лендинга и основная копирайтинговая подача;
- app/globals.css — палитра, типографика, сетка и адаптив;
- public/images — локальные изображения;
- schemas/lead.ts — единая схема заявки;
- lib/lead-delivery.ts — mock/Telegram transport.

Бренд и контакты централизуйте в этих файлах перед адаптацией. Все demo-данные отмечены в коде и интерфейсе.

## Маршруты

- / — лендинг;
- /privacy — демонстрационная политика обработки данных;
- /api/leads — POST Route Handler;
- /robots.txt, /sitemap.xml, /manifest.webmanifest;
- собственная 404-страница.

## Деплой

Основной вариант по условиям проекта — запуск на ПК и хранение в GitHub.

Если позже понадобится Vercel, импортируйте GitHub-репозиторий, задайте переменные из .env.example и используйте LEAD_DELIVERY_MODE=mock для preview. Telegram включайте только после добавления server-only секретов в Project Settings. После публикации проверьте canonical, sitemap, robots, OG и /api/leads. Локальная файловая система Vercel не является постоянным хранилищем.

## Аналитика

lib/analytics.ts содержит no-op адаптер событий. Счетчики не подключены без согласия. Для Яндекс Метрики или другого сервиса реализуйте отправку внутри trackEvent, не меняя компоненты.

## WebMCP

В поддерживаемом браузере сайт регистрирует два необязательных инструмента: расчет ориентировочной стоимости по той же конфигурации, что использует экранный калькулятор, и переход к форме консультации. В обычных браузерах эта интеграция незаметно отключается и не влияет на интерфейс.

## Перед реальным коммерческим запуском

Обязательно замените название, контакты, юридические данные, проекты, цены, кейсы, отзывы, показатели, гарантийные условия, политику и AI-изображения. Проверьте договор у юриста, настройте реального оператора персональных данных и production rate limit.
