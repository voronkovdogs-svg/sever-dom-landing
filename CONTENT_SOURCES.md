# Источники контента и изображений

## Статус проекта

Весь контент создан для вымышленной компании «Север Дом». Он не описывает реальные объекты, заказчиков, гарантии или деловые показатели.

## Изображения

Изображения созданы встроенным инструментом OpenAI Image Generation специально для этого демонстрационного проекта 21 сентября 2026 года. Внешние фотостоки, чужие логотипы и материалы реальных компаний не использовались.

| Файл | Назначение | Статус |
| --- | --- | --- |
| public/images/hero/sever-dom-hero.webp | главный экран и концепт-кейс | AI-концепт, не фотография построенного объекта |
| public/images/projects/lesnoy-128.webp | карточки проектов и кейс | AI-концепт |
| public/images/cases/zimniy-186.webp | карточки проектов и зимний кейс | AI-концепт |
| public/images/og/sever-dom-og.webp | Open Graph / X preview | AI-концепт с демонстрационным текстом |

Изображения сжаты в WebP и хранятся локально. Перед использованием для реального бизнеса замените их фотографиями собственных объектов с подтвержденными правами и обновите этот файл.

## Тексты и данные

Проекты, цены, сроки, отзывы, кейсы, статистика и контакты написаны специально для макета. Контактный домен example.com зарезервирован для примеров.
